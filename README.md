# Google Authentication Practice

A simple project built to learn and implement Google Authentication using OAuth 2.0. This project demonstrates how users can securely sign in with their Google accounts and access protected routes after successful authentication.

## Features

* Google Sign-In integration
* User authentication using OAuth 2.0
* Secure session/token handling
* Protected routes for authenticated users
* Logout functionality

## Tech Stack

* ReactJS
* NodeJS
* Google OAuth
* MongoDB

## Learning Objectives

This project was created to gain hands-on experience with:

* OAuth 2.0 authentication flow
* Google Identity Services
* Authentication and Authorization concepts
* Token handling and user session management
* Full-stack integration between frontend and backend

## Setup

1. Clone the repository
2. Install dependencies

   ```bash
   npm install
   ```
3. Configure Google OAuth credentials
4. Add environment variables
5. Run the application

   ```bash
   npm start
   ```
